Featured build

EduCore

In progress

A Go + PostgreSQL REST API for education management — JWT auth, role-based access control, and student records, built on the standard library without a framework.

What I built

  • Auth & hashing. Registration and login with bcrypt-hashed passwords and signed JWTs.
  • Role-based middleware. A route can require a specific role — admin-only, for example — before it runs.
  • Fail-fast secrets. The JWT signing key used to be a string in the source. Now the server won't start without it set in the environment.
  • Tested where it counts. Password hashing has unit tests — hash produced, correct password verifies, wrong one is rejected.
Honestly, not built yet
  • Create/update/delete exist as internal functions, not wired to routes.
  • No input validation beyond the database schema.
  • No React frontend, teachers, courses, attendance, or grades.
